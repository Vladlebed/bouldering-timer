# Боулдеринг · Таймер ротаций

Статическое веб-приложение для организатора соревнований. Для запуска нужен современный браузер с Web Audio API.

## Локальный запуск

В папке проекта выполните `python3 -m http.server 8000` и откройте `http://localhost:8000/`. В браузере выберите время и количество ротаций, подключите колонки и нажмите «Проверить звук». Громкость также зависит от настроек системы и колонок.

- Один монитор. Нажмите «На весь экран». Старт и пауза доступны на табло. Esc или «К пульту» возвращают к настройкам.
- Два монитора. Нажмите «Открыть второе окно», перетащите табло на нужный монитор и разверните. Управление и звук остаются в исходном окне. Оба окна должны быть в одном браузере и профиле.
- «Сбросить» останавливает раунд и возвращает к первой ротации. При заданном количестве раунд заканчивается сигналом окончания последней ротации. Если пульт перезагрузится во время раунда, нажмите «Включить звук» для последующих сигналов.

Перед соревнованиями проверьте слышимость сигналов с места спортсменов и отключите автоматический сон компьютера. Оставляйте открытым пульт, пока идёт отсчёт.

## Исходники

Разметка находится в `index.html`, оформление в `styles.css`, сигналы и управление в `app.mjs`, расчёт ротаций в `timer.mjs`. Проверка логики запускается командой `node --test timer.test.mjs`.

Для GitHub Pages разместите содержимое этой папки в корне отдельного репозитория и выберите публикацию из корня ветки. Сборка не нужна.
